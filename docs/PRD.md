# PRD: the Word

## 목표
타로/운세를 찾는 한국 MZ세대에게 성경 말씀 한 구절을 자연스럽게 전달하는 웹앱.
"오늘은 타로 뽑듯이 시작했다가 말씀을 만나는 경험"을 만든다.

## 사용자
- **1차**: 한국 MZ세대 비기독교인 — 불안, 위로, 방향을 찾는 사람
- **2차**: 기독교인 MZ세대 — 매일 말씀을 감성적으로 소비하고 싶은 사람
- **유입**: 인스타그램 스토리 공유 → 모바일 웹 직접 접속
- **타겟 브라우저**: 모바일 Safari 15+, Chrome Android 100+

## 핵심 기능 — Phase 1 MVP

| # | 기능 | 설명 |
|---|------|------|
| 1 | 감정/상황 주제 휠 | 6구역 D3 원형 휠, 클릭 시 스핀 |
| 2 | 랜덤 구절 뽑기 | 착지 카테고리에서 랜덤 1구절 선택 |
| 3 | 말씀 카드 | 구절 + 출처 + 카테고리 뱃지, 라벤더 테두리 카드 |
| 4 | 이미지 저장 | 1080×1080px PNG, html2canvas |

**Phase 1은 한국어 전용.** 영어 표시는 Phase 2에서 추가.

## 주제 카테고리 (6구역)
| 구역 | 감정/상황 | 색상 |
|------|-----------|------|
| 너무 힘들 때 | 위로, 지침 | Amber |
| 불안하고 무서울 때 | 믿음, 두려움 | Purple |
| 관계가 힘들 때 | 사랑, 용서 | Coral |
| 뭔가 잘 됐을 때 | 감사, 기쁨 | Green |
| 앞이 안 보일 때 | 소망, 미래 | Teal |
| 선택해야 할 때 | 지혜, 결정 | Blue |

## 소셜 공유 / OG 메타
Instagram 링크 공유 시 미리보기 품질이 클릭률에 직결됨.

| 항목 | 값 |
|------|-----|
| `og:title` | "the Word — 오늘의 말씀" |
| `og:description` | "지금 이 순간 당신에게 필요한 말씀을 뽑아보세요" |
| `og:image` | `/og-image.png` (1200×630px 정적 이미지, Phase 1) |
| `og:type` | `website` |
| `og:url` | `https://theword.app` |
| `twitter:card` | `summary_large_image` |

## 사용자 흐름 (Happy Path)
1. 앱 진입 → 6구역 휠 + 안내 문구 2줄:
   - "마음을 담아 돌려보세요"
   - "오늘 당신에게 필요한 한 마디가 기다리고 있어요"
2. 휠 클릭 (중앙 원 또는 휠 전체 영역) → 스핀 (2.8–3.5초)
3. 착지 → **휠 fade out (300ms) → 같은 자리에 카드 fade in (400ms)**
   스크롤 없음. 안내 문구도 함께 숨겨짐.
4. 카드 확인 → 버튼 세로 배치:
   - **[저장하기]** — 저장 후 버튼 텍스트 "저장됐어요 ✓" (1.5초 후 복귀)
   - **[다시 뽑기]** — 카드 fade out → 휠 fade in, 안내 문구 복귀
5. 같은 구절 재등장 허용 (Phase 1)

## 에러/엣지케이스 UX
| 상황 | 처리 |
|------|------|
| 스핀 중 재클릭 | 무시 (휠 클릭 비활성화) |
| 카테고리 구절 없음 | 전체 구절 풀에서 랜덤 fallback |
| 이미지 저장 실패 | "저장에 실패했어요. 다시 시도해주세요" 인라인 메시지 (#BFFFCC 배경) |
| 모바일 Safari 저장 | `navigator.share()` 로 공유 시트 열기 |
| 폰트 로드 전 캡처 | `document.fonts.ready` 대기 후 실행 |

## MVP 제외 사항 (Phase 2로 이연)
- 2단계 휠 (주제 선택 후 구절 별도 스핀)
- 영어 표시 옵션
- 터치 스와이프 + 물리 관성
- 작대기(레버) 인터랙션
- 대한성서공회 정식 저작권 허가
- Buy Me a Coffee 수익 연동
- 세션 내 중복 구절 방지
- 동적 OG 이미지 (구절별)

## 성공 기준
- 모바일에서 휠 클릭 1회 → 카드 확인 → 저장까지 3탭 이내
- 저장된 1080×1080 이미지가 인스타그램 스토리에 바로 공유 가능한 품질
- "교회 앱이잖아" 느낌 없는 디자인 — 비기독교인 첫 방문자도 거부감 없이 사용

## 앱 정체성
운세는 "너의 미래는 이래"라고 말하지만, 말씀은 "너는 사랑받는 존재야"라고 말한다.
기능이 아니라 메시지가 차별점이다.
